Protezione automatica per le tue tapparelle – prima che arrivi la grandine.
Questa app collega il tuo Homey al sistema di allerta grandine di hagelschutz-einfach-automatisch.ch e protegge le tue tapparelle in modo affidabile dai danni causati dalla grandine. Non appena un'allerta diventa attiva, Homey reagisce automaticamente – ad esempio sollevando le tapparelle o inviando una notifica.

Funzioni
* Allerta grandine automatica tramite un Flow di Homey
* Riconoscimento di allerta, allarme di prova e cessato allarme
* Monitoraggio della connessione API con allarme in caso di guasto
* Watchdog se l'API smette di rispondere
* Intervallo di interrogazione configurabile (predefinito: 120 secondi)
* Completamente disponibile in tedesco, inglese, francese e italiano

Requisiti
* Homey (Pro) con accesso a internet
* Registrazione su hagelschutz-einfach-automatisch.ch
* Numero di serie valido (deviceId) e ID tipo hardware (hwtypeId)

Ideale per
Proprietari di immobili, amministrazioni immobiliari, architetti ed elettricisti in Svizzera che desiderano combinare una moderna automazione degli edifici con una protezione automatica dalla grandine.
